# tugas-frontend-crud-aplikasi-asuransi
Tugas aplikasi asuransi CRUD Front End saja tanpa database (data disimpan di local web browser / cache). 
Dibuat dalam 2 hari.
Dengan Framework React Vite dan Ant Design.

*Untuk Run Aplikasi, ketikan berikut pada Command Prompt masuk ke folder project, install node-modules project, dan Run Aplikasi:
cd antd-tugas-aplikasi-asuransi
npm install
npm run dev


*Untuk Stop localhost aplikasi:
Ctrl + C pada layar Command Prompt yang sebelumnya digunakan untuk Run Aplikasi.
